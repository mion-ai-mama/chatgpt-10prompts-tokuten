# ChatGPTの潜在能力を引き出す10のプロンプト技術（要件定義）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論・ビルド不要の静的サイト）
- 操作者: ブラウザのエンドユーザー / AI本体: なし / MCP: なし / 自社DB: なし / フロントUI: あり
- 種別: Web型（GitHub Pages） / 配布: マイ専用

## 1. 目的

リールから誘導する無料特典。ChatGPT初心者〜初級者の40〜50代女性が、10個のプロンプトをワンタップでコピーして試せる。最終ゴールはLINE登録への誘導。成果・精度は保証しない。

## 2. 構成

ファーストビュー → 教科書CTA → 使い方（3ステップ）→ 目次（10技術）→ TECHNIQUE 01〜10（どんなときに使う／コピペ用プロンプト／使い方のポイント）→ 悩み→つなぎ→LINE誘導

## 3. 実装

- プロンプト全文を折りたたまず表示。コピーボタンは成功時「コピーしました！」を約2秒表示。クリップボードが使えない環境では本文を選択状態にして手動コピーを案内
- ［ここに入力］は黄色ハイライト。コピーされる文章は制作指示書のとおり（欠落なしを照合済み）
- 技術名は説明用の呼称であり学術的な正式名称ではない旨を使い方に明記

## 4. 公式確認の要否

製品の価格・仕様に関する記載なし（ChatGPTのカスタム指示への言及のみ）。
